# Учёт носков на складе (тестовое задание Райффайзен CIB)

Простой HTTP-сервис на Java для учёта прихода, расхода и остатков носков на складе.

Исходное задание: https://github.com/Hexlet/ru-test-assignments/blob/main/java/raiffeisen/cib-interns-test-task.md

## Что делаю (выбранный объём)

- Все 3 HTTP-метода из условия: POST /api/socks/income (приход носков), POST /api/socks/outcome (списание со склада) и GET /api/socks (подсчёт остатка по цвету и содержанию хлопка: moreThan, lessThan, equal).
- Реализация на стандартной Java с использованием встроенного HttpServer из JDK, без Spring и внешних библиотек.
- Хранение данных в оперативной памяти в обычном списке ArrayList.
- Проверка входных данных и возврат кодов ответа 200, 400, 405 и 500.

## Что не делаю и почему

- Подключение базы данных PostgreSQL и миграций Liquibase или Flyway — на настройку не хватит отведённых 6–8 часов, а основная логика склада работает и с хранением в памяти.
- Упаковка в Docker и деплой на облачный сервер — вынесено за рамки базового сценария.
- Форк и pull request в репозиторий компании — задание взято из каталога Hexlet, поэтому решение оформлено в отдельном открытом репозитории.
